# HTX 火宝配图库

54 款来自 [Figma 火宝角色合集](https://www.figma.com/design/65lorIZe3ZfsWhJEJUZq0S?node-id=7389-2) 的完整原图。保留原始像素及透明度，编号与原图 SHA-1 逐项核对。

- `assets/`：完整原图，海报选用这里的文件。
- `thumbs/`、`overview-*.jpg`：仅用于选图。
- `manifest.json`：动作、关键词、尺寸、透明度、SHA-256 及来源节点。
- `index.html`：可搜索预览。

基础角色为额前单个蓝角与桃尖头型；现成素材的服装、道具按原图保留，不由生成规则改写。
