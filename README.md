## HTX 品牌 Skill 与配图库

- [htx-brand skill](skills/htx-brand/SKILL.md)：自动搜索、查看和下载 L3 标准版白天配图。将 `skills/htx-brand` 整个目录安装到个人 skills 目录即可使用，包含字体、Logo、背景及取图脚本。
