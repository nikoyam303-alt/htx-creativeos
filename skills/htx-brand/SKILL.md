# HTX 品牌视觉

统一制作普通社媒海报与复杂品牌物料。

## 流程

1. 逐字锁定用户或源文档内容，不增写、不润色。
2. 普通社媒默认 1080×1080；信息较多时用 1080×1280。复杂长图按真实内容决定高度。
3. 使用 Skill 字体、Logo 和背景；本地制图使用 HTML/CSS 排版，用户指定 Figma 时使用原生图层与相应 MCP 技能；只在源内容或用户要求中出现 CTA、二维码、时间、说明和装饰。
4. 导出最终 PNG 并检查一次；发现裁切、碰撞、异常换行或留白失衡时做针对性修正。用户要求时输出可编辑 SVG。

## 品牌基础

- 品牌蓝 `#0066FF`；正文黑 `#000000`；白 `#FFFFFF`；卡片 `#F6F6F6`；标签 `#EBFF3A`。
- 只用 400 / 500 / 700 字重；禁用 800、900、black、斜体、拉伸字体。
- 默认中文用 `assets/fonts/` 内 HarmonyOS Sans SC，英文用 Urbanist；用户要求统一字体时，中文、英文和数字均可使用 HarmonyOS Sans SC，并在当前物料中保持一致，不将单次选择改成全局默认。中英混排不得用负字距压缩英文。
- 使用官方 Logo。1080px 画布 Logo 为 100×100，距上、右各 60px；左右安全边距默认 80px，硬下限 64px。

## Figma 与局部修订

- Figma 文案使用原生 Text 图层；SVG 文案保留 text 元素。除非用户明确要求，否则禁止文字转曲，不以轮廓路径或整图代替可编辑文字。
- 修改文字前检查目标环境中的字体与字重是否可用并完成加载；本地有字体不代表 Figma 可用。缺字体时说明缺失项，先完成不依赖字体的工作，不擅自转曲；替代字体须依据用户已有选择，未指定时再确认。交付前检查文字可编辑性、字体加载和换行。
- 局部调整仅修改用户指定的属性，保留用户已调整的其他内容、位置、尺寸和样式；先读取当前画布，不用旧坐标覆盖用户修改。
- 删除内容后按相邻版块的间距收紧残留空白；画布尺寸变化后复查 Logo 是否仍在画布内、底部安全距离及内容碰撞。Logo 方位可按用户或参考图调整，不固定复用上一次位置。
- 区分元素的水平居中与文本段落居中；统一左边距时对齐同级版块的内容边界。

## 默认配图：GitHub L3 标准版白天素材库

- 默认从 GitHub 仓库 `nikoyam303-alt/htx-creativeos` 的 `assets/illustrations/l3-standard-light/` 自动选取配图。读取 [manifest.json](https://raw.githubusercontent.com/nikoyam303-alt/htx-creativeos/main/assets/illustrations/l3-standard-light/manifest.json)，仅选择 `tier=L3标准版`、`theme=light` 的素材。用户指定图片优先。
- 每次按本次文案的核心主题重新筛选，先读名称、图意描述和中英文关键词，再查看候选图或联系表确认实际图意及构图。不要固定复用上次素材；同名素材以唯一 ID 区分，不猜文件路径。
- 使用本 skill 的 `scripts/l3_assets.py --query "当前主题"` 搜索；选定后执行 `scripts/l3_assets.py --id 素材ID --output 工作目录/配图.png`，自动下载并校验 SHA-256。脚本只使用 Python 标准库，不要求 Figma 登录或用户手动添加图片。详细命令和回退规则见 `references/l3-asset-library.md`。
- 库内 PNG 由原始 256×256 图层原生 4× 导出为 1024×1024，保留透明度；只去除外层展示画板底色，不裁切、变形、调色或重绘配图。根据最终输出像素选取尺寸，默认不将图片放大超过原始像素；需要更大图时从来源节点重新高倍导出，不把插值放大称为高清原图。
- 记录所用素材 ID 与来源节点。Figma 链接仅用于溯源和后续维护，不再作为日常制图的默认取图入口；仓库无法访问时可使用已校验缓存，不静默混用黑夜版、L1/L2、L3营销版或产品表达类。没有合适配图时明确说明缺口，不让用户重复手工添加已有库内素材。

## Hero 与背景

- 默认使用贯穿画布的上蓝下白柔和渐变，不加网格、噪点、阴影、霓虹或未提供装饰。
- 白色或半透明配图占比较大时，把浅蓝与白色过渡区向上提，减少中部蓝色面积。1080×1080 可从 `#62A0FB 0% / #BED8FC 22% / #EEF5FF 48% / #FFFFFF 76%` 起调，不把停点写死。
- 不固定配图方位。先检查素材主体的明度、透明区域和边缘与各背景区的对比度，再选择左、右、上或下构图；浅色或半透明细节避开蓝色区，优先落在白色或高对比区域。原样等比放置用户配图，不裁切、变形、调色或加滤镜。
- 不复用上一张海报的固定坐标或比例。先为 Logo、标题、配图和信息区划分互不冲突的安全框，再按当前内容的字数、素材形状和剩余空间机动调整位置与整体尺度；留白明显失衡时，优先放大核心标题组或配图并重新定位。
- 先锁定配图安全框，再让标题在剩余区域按语义换行。主标题整组只使用一个字号；需要适配时只能同步缩放整组标题，不得单独放大数字、缩小单位或让不同行字号失去依据。字体加载完成后检查标题右边界、Hero 下边界和配图碰撞。
- 主标题默认黑色，核心短语可用品牌蓝建立层级，但保持同一字号和字重，除非用户明确要求改变。Hero 高度随内容调整，不制造大块空白或拥挤。

## 信息承载

- 方图底部不叠加整块白色承托层，只保留真实内容小卡片的 `#F6F6F6` 背景；长图正文外层保持白色。
- 先按独立信息组数量选择承载方式：只有一组补充内容，或画面不需要卡片时，优先用上下两条低透明度细分割线形成轻量信息区；两组及以上并列信息可使用卡片以建立清晰分组。
- 分割线只用于分区和丰富留白，不做厚重边框。默认用黑色或灰色、约 12%–24% 透明度、1–2px 粗细；宽度限制在所属信息区内，不得跨越或切割配图安全框，并给文字保留舒展的上下间距。
- 简短利益点优先使用并列小卡片。同组卡片共享同一字号、颜色、字重、间距和对齐逻辑。
- Taker / Maker、序号或礼物名等短分类可使用 `#EBFF3A` 紧凑圆角标签、纯黑文字；标签只包裹短文字。1080px 可从 40px、内边距 12px 20px、圆角 16px 起调。
- 信息卡片中的比例、费率或金额可使用“大数字＋小单位”：核心数字为品牌蓝、700 字重；单位为黑色、500 字重和较小字号；两者保留明确间距，1080px 可从 12px 起调。此规则不得用于主标题。
- 卡片文字框宽度使用卡片宽度减去左右内边距，避免过窄文本框或遗留手动换行导致提前折行；按完整语义换行，避免单字落行。
- 卡片高度和内边距按内容收紧。已有卡片边界时不再堆叠分割线、竖线或额外边框；不要同时用卡片和分割线表达同一层级。

## 复杂内容与底部

- 表格内部保持白色；短内容尽量单行，换行按完整语义。表头 `#F5F7FA`，表格线 `#E8E8E8`。
- 底部保持白色，禁止蓝色页脚或独立免责声明色块。
- CTA 使用品牌蓝圆角矩形、白字，不用胶囊形；二维码仅在源文档包含或用户明确要求时出现。

## 输出与质检

- PNG：画布与导出 viewport 一致；检查真实像素、字体加载、安全区、文字溢出和背景连续性。普通社媒只交付最终 PNG，除非用户要求源文件。
- SVG：文字、形状、渐变和 Logo 分层可编辑；禁止嵌入整张 PNG 或使用 `foreignObject` 伪装可编辑结构；用 `xmllint --noout` 验证。
- 交付前确认：文案逐字完整；标题与配图填充 Hero 且互不碰撞；主标题内部字号一致；同组卡片逻辑一致；底部保持白色。
