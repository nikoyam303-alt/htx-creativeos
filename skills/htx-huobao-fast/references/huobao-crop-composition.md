# 火宝半身近景：用户确认案例

来源：[用户调整稿](https://www.figma.com/design/7mCMRqTdCl8fKM5xxTmkdO/Codex?node-id=1735-2257)，Page 7。对比：[原全身稿](https://www.figma.com/design/7mCMRqTdCl8fKM5xxTmkdO/Codex?node-id=1737-100)。画布均为 1080×1080；素材 HB-150，原图 1240×1443，单角、张开双臂。

| 项目 | 原全身稿 | 用户调整稿 |
| --- | --- | --- |
| 主标题字号 | 90px | 约 110px（109.914） |
| 主标题宽度 | 630px | 770px |
| 活动主题字号 | 30px | 约 36.64px |
| 副标题字号 | 32px | 约 39.08px |
| 标题组左边距 | 80px | 68px |
| 火宝图层窗口 | 500×581.85px | 704×606px |
| 火宝位置（相对画布） | x=500，y=438 | x=418，y=500 |
| 图片显示 | FIT，全身 | CROP，半身取景 |
| 越界 | 无 | 右侧约 42px，图层底部约 26px |

标题组整体约放大 22%；火宝按宽度约放大 41%。用户稿保持原图比例，用裁切窗口和画布裁切形成腰部截止的半身近景；右边部分手臂／手掌出画，头顶、蓝色单角、面部表情和胸前标识保留。人物不再是留有四周空白的全身小摆件，而成为画面下半部的视觉主体。

复用的是“放大标题、放大 IP、腰部取景、侧边出画”的判断，不是照抄数值。标题长度、角色姿态和画布比例改变时重新布局。该例还移除了 CTA，但用户本次强调的是标题尺度与 IP 裁切，不因此设定所有海报必须删除 CTA。
