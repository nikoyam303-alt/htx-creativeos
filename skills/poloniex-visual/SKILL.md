# Poloniex 品牌视觉

先读 [品牌规则](references/brand.md)。制作社媒或选择视觉方向时再读 [社媒参考与来源](references/social.md)。

## 决策原则

- 用户本次要求优先；其次使用对应场景的明确规范，再参考已完成设计稿。不要把单张创意稿的字体、材质或布局提升为全品牌要求。
- 品牌识别以黑色/近黑底、绿色重点、白色信息和官方 Logo 为基础。图像可以是写实、3D、插画或图形排版，随内容选择。
- 当前社媒仅使用绿色体系与黑白灰；紫色、红色已停用，站内橙色不在当前范围。字体强制 Proxima Nova，不再使用苹方或其他创意字体。不要套用 HTX 蓝白或 Deepcoin 黑金规范。
- 先确定文案、尺寸、语言、主要信息与交付目的。信息不足但不影响制作时采用参考尺寸并说明；金额、日期、活动规则和链接不得编造。

## 官方插画库

需要插画时先读 [素材检索与下载](references/illustrations.md)，优先检索 GitHub 中的 Poloniex 深色素材。

## 制作流程

1. 从文案确定主标题、关键利益点、补充信息与行动入口；每张图建立明确阅读顺序。
2. 选择参考：普通活动优先大标题与单一主视觉；品牌情绪帖通过构图与摄影表达；数据/公告优先信息清晰。所有方向均使用 Proxima Nova。
3. 使用官方 Logo、币种标识和原始素材。优先从来源文件导出，保持比例和内部颜色；不能用字体打字或生成模型代替官方 Logo。无法读取资产时明确缺项，不声称已完整交付。
4. 如需 AI 图像，按当前可用生图工具生成背景或主体，预留文案区域。正式标题、金额、日期、CTA 和 Logo 独立排版；图中已有的非正式文字需要清理。用户指定工具时遵循其选择。
5. 按画布重新构图，多尺寸与多语言不做机械拉伸。长文案优先重排、缩短获准可改的文字或分图，避免把所有字缩小。
6. 用户要求 Figma 可编辑交付时，使用可用 Figma 技能，文字与版式保持可编辑、位图主体独立；未指定 Figma 目的地时可先交付本地预览与可编辑源文件，不擅自改动参考文件。
7. 导出后查看实际成图，再修正发现的问题。交付预览、可编辑源文件（如任务要求）及明确的文件/节点链接。

## 质检

- Logo 来源正确、比例正常、对比足够；没有其他品牌残留。
- 字体必须为 Proxima Nova；缺失字体或字符覆盖不足时明确报告，不擅自替换，不把替代字体稿标为合规终稿。
- 主次清楚，亮绿用于重点；仅使用绿色体系和黑白灰，不引入紫红橙点缀。
- 所有文案、金额、单位、日期、时区、链接与用户资料一致。
- 无裁切、遮挡、乱码、孤立断词；小尺寸预览仍可阅读。
- 图像没有畸形主体或错误币种符号；AI 图像中的文字未冒充正式信息。
- 多语言单独检查断行和字形覆盖；源文件确实可编辑，导出尺寸正确。
